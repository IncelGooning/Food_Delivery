# FoodDelivery – система доставки еды (консольное приложение)

## Описание

Проект представляет собой консольное приложение на Python, которое имитирует работу сервиса доставки еды. В системе реализованы три роли: клиент, ресторан и курьер. Все данные хранятся в текстовых файлах.

## Запуск

1. Установите Python 3.6 или новее.
2. Скачайте проект и откройте терминал в корневой папке.
3. Выполните команду:

```bash
python main.py
```

При первом запуске автоматически создаётся папка data/ с необходимыми файлами.

## Роли и возможности

### Клиент

1. Просмотр ресторанов с фильтром по типу кухни.
2. Просмотр меню выбранного ресторана.
3. Формирование заказа (выбор блюд и количества).
4. Просмотр истории своих заказов с деталями.
5. Отмена заказа на этапах «Ожидает подтверждения» или «Готовится».

### Ресторан

1. Просмотр заказов, адресованных этому заведению.
2. Перевод заказа на следующий статус:
2.1. «Ожидает подтверждения» → «Готовится»
2.2. «Готовится» → «Готов к выдаче»
3. Добавление новых блюд в своё меню (название, цена).
4. Удаление блюд из своего меню.

### Курьер

1. Просмотр заказов, готовых к выдаче (статус «Готов к выдаче»).
2. Принятие заказа в доставку (статус становится «В пути», курьер фиксируется).
3. Завершение доставки (статус «Доставлен»).
4. Просмотр списка своих доставленных заказов.

## Форматы файлов (примеры)

1. users.txt – хранит пользователей:

логин|пароль|роль

Пример:

alex|qwerty123|client

2. restaurants.txt – хранит рестораны:

логин_владельца|название|тип_кухни

Пример:

pizza_hub|Pizza Hub|Итальянская

3. menu.txt – хранит блюда:

id_блюда|логин_ресторана|название|цена

Пример:

101|pizza_hub|Маргарита|450.50

4. orders.txt – хранит заказы:

id_заказа|клиент|ресторан|состав_блюд|статус|курьер

Состав блюд кодируется строкой: Название:цена:количество;Название2:цена2:количество2

Пример:

5|alex|pizza_hub|Маргарита:450.50:2;Кола:120.00:1|В пути|ivan_courier

## Примечания

Система полностью автономна, не требует интернета или базы данных.
При регистрации ресторана создаётся и пользователь с ролью restaurant, и профиль ресторана.
Статусная модель заказа (обязательный порядок):

Ожидает подтверждения → Готовится → Готов к выдаче → В пути → Доставлен.
Допустим также статус «Отменён» (только из первых двух статусов).
Ресторан не может перепрыгивать через статусы.
Курьер может взять заказ только после того, как ресторан перевёл его в «Готов к выдаче».
Заказ нельзя отменить, если он уже «Готов к выдаче», «В пути» или «Доставлен».
Все изменения (добавление блюд, смена статусов, отмена) немедленно сохраняются в файлы.

Рейтинг блюд и ресторанов.
